# Teste de pacote Ventoy

Este wizard usa o projeto open source `ventoy/Ventoy` no GitHub.

O fluxo baixa o release mais recente, escolhe o pacote compactado do sistema atual e descompacta em uma pasta local de teste.

Por seguranca, este wizard **nao instala o Ventoy em nenhum disco/USB**. Ele apenas baixa, descompacta e abre a pasta de destino.
