# Politica de privacidade do wizard de exemplo

Este documento demonstra como um termo de privacidade declarado no manifesto aparece antes das permissoes.

O wizard de exemplo consulta informacoes basicas do sistema somente quando a permissao correspondente e aceita. Essas informacoes sao usadas para preencher a tela demonstrativa local e nao sao enviadas para terceiros por este exemplo.

## Dados locais

Os eventos de auditoria podem registrar a URL do manifesto, permissoes aceitas e resultados de chamadas permitidas para fins de rastreabilidade local.
